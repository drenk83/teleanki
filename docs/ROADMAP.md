## Будем делать

- **Отвлекающие отдельно.** В хранении только неверные ответы теста. Кнопки на показе = ответ + отвлекающие. Импорт: `choices` — тоже только неверные.
- **Again в ту же сессию.** Карточка уходит в конец очереди. SM-2 пишется сразу. Каждое Again считаетcя в дневной лимит. Последняя оценка побеждает.
- **Картинки.** Одно необязательное фото на сторону (вопрос / ответ). Текст остаётся обязательным. Хранить Telegram `file_id`, без своего диска. JSON-импорт без картинок. Quiz: фото на сторонах ок, варианты только текст.
- **Markdown** в вопросе и ответе.
- **Напоминание due.** Раз в день: есть карточки к повторению.
- **Онбординг.** Переписать `/start` и подсказки.
- **Шеринг колод** между пользователями.

## Не берём

FSRS, теги, экспорт, поиск, перенос карточек, аудио, cloze, сохранение FSM через рестарт, вебхуки.
