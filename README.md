# teleanki

Telegram-бот интервальных повторений в стиле Anki.

Работает только в личке. У каждого пользователя свои колоды и карточки. Режимы: вспомнить, тест, ввод. «Начать» в стандартном режиме идёт по карточкам, которым пора (SM-2); свободный — все выбранные без записи.

## Запуск

Нужны `TG_TOKEN` и `DATABASE_URL`. Скопируй `.env.example` в `.env`.

```bash
docker compose up -d
go run ./cmd/bot
```

```bash
go test ./...
go vet ./...
```
