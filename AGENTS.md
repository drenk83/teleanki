# AGENTS.md

Telegram-бот интервальных повторений. Модуль `github.com/drenk83/teleanki`. UX — RU; код, логи, коммиты — EN. Ветка `develop`. Long polling (`go-telegram/bot`).

Язык домена: [CONTEXT.md](CONTEXT.md).
Продукт: [README.md](README.md).
Будущее: [docs/ROADMAP.md](docs/ROADMAP.md) — не делать без явного запроса.

## Команды

```bash
go run ./cmd/bot
go build -o teleanki ./cmd/bot
go test ./...
go vet ./...
gofmt -l .
```

Нужны `TG_TOKEN` и `DATABASE_URL` (env или `.env`). `.env` не коммитить. Локальная БД: `docker compose up -d`.

## Правила

- `cmd/bot` тонкий. Хендлеры и middleware — в `internal/telegram`.
- Карточку менять только через функции `internal/domain`. Невалидный тест не сохранять. Режим тест писать только с валидными вариантами. Правка ответа у теста заменяет старый ответ в вариантах.
- Варианты теста включают ответ. Уникальность и «ответ среди вариантов» — без учёта регистра.
- Ввод: `TrimSpace` + `EqualFold`.
- Переворот только у вспомнить и ввод.
- Хендлеры ходят в `internal/storage`, не в pgx. Миграции — goose.
- Карточка и начальное повторение — одна транзакция. Импорт новой колоды — одна транзакция. Оценка в «Начать» — `reviews.Apply` (повторение и счётчик дня вместе).
- Пользовательские строки — в `internal/config`.
- SM-2 живёт в `internal/scheduler`. Формулу и оценки не менять без запроса. Again не возвращает карточку в ту же сессию.
- Невалидный тест в сессии учёбы пропускать молча.
- Импорт: схема в `/help`; пустой `cards` — ошибка. JSON только данные.
- Только личка. В группе отказ только на команды (`/…`); остальное — тишина.
- FSM в памяти. `/help` не сбрасывает. `/start`, `/menu`, `/decks`, `/newdeck`, `/learn` сбрасывают. Клики правят сообщение бота; текст или файл пользователя — новое сообщение.
- Перед действием — колода и карточка принадлежат пользователю. На callback — `AnswerCallbackQuery`.
- Тесты обязательны: `internal/domain`, `internal/scheduler`, `internal/learn`.
- Логи: `slog` JSON в stdout, ключи EN. Не печатать и не логировать `TG_TOKEN`.
- Коммиты: короткие lowercase EN. Не коммитить, пока не попросили.
- Пустые `.go` без `package` не оставлять.
- Не добавлять вебхуки, FSRS, нечёткий ввод и зависимости вне `go.mod` без запроса.
